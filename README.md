# 📊 Data Science Projects Portfolio

A collection of end-to-end Data Science, Machine Learning, Deep Learning, and Interactive Analytics web applications built with **Python**, **TensorFlow**, **Streamlit**, and **Plotly**.

---

## 📁 Projects Overview

| Project | Description | Primary Tech Stack |
| :--- | :--- | :--- |
| [🌿 Leaf Disease Detection](file:///e:/data%20science%20project/Leaf%20Disease%20Detection) | Plant leaf image disease classification with treatment guidelines & performance metrics | TensorFlow/Keras (MobileNetV2), Streamlit, OpenCV |
| [🦠 COVID-19 Data Analysis](file:///e:/data%20science%20project/corona) | Dynamic interactive dashboard for global COVID-19 case tracking, KPIs, and regional trends | Streamlit, Pandas, NumPy, Plotly |

---

## 🚀 How to Run

### 1. Leaf Disease Detection Application
```bash
cd "Leaf Disease Detection"
pip install -r requirements.txt
streamlit run app.py
```

### 2. COVID-19 Data Analysis Dashboard
```bash
cd corona
pip install -r requirements.txt
streamlit run app.py
```
